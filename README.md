# Planta Generadora Inteligente con Arduino
Proyecto integrador de Informática II - UTN FRM

## Integrantes
- Salinas Francisco
- Spinoza Lucas
- Vilca Javier

## Descripción
Micro-planta eólica controlada por Arduino que mide variables climáticas
y eléctricas, gestiona la carga de baterías y envía los datos a una interfaz
en Processing.

## Estructura
- `arduino/`: código del microcontrolador
- `processing/`: interfaz gráfica en PC
